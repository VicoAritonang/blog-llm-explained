# NeuroLab Observatory — original asset kit

25 standalone modules + one assembled laboratory, glTF 2.0 binary (.glb).
Original procedural geometry, no downloaded models, texture files, or fonts.

## Use

- Coordinates: meters, +Y up, +Z forward. Instruments centered at floor level.
- Vector arrow: one-meter length along +Y; pivot at its base.
- `manifest.json`: geometry counts, bounds, bytes, hashes, materials, sockets.
- `layout.json`: room dimensions, eight stations, camera positions, POV spawn.
- Named `socket_*` nodes retain role metadata in glTF extras. Scope lookup to the relevant instrument subtree; local socket names may repeat.
- `demo_*` nodes show static illustrative content. Hide them when installing live matrix/particle renderers. No numbers are claimed to be real model output.
- `dynamicNodes` in the manifest documents animation bindings. Wildcards describe node name prefixes, not glTF animation clips.
- No baked animation, physics, textures, text meshes, or numeric computation is included. Use runtime text, instancing, and the scene timeline described in system.md.
- `lab-assembled.glb` is a layout reference. Load either this assembly or individual modules; do not double-load both. Production should batch static geometry and instance repeated cells/tiles.
- The MLP module uses a 4→12→4 silhouette, independently of the numerical demo profile (8→32→8).

## Rebuild and inspect

From repository root:

```sh
npm ci
npm run assets:generate
npm run assets:validate
npm run assets:preview
```

Open http://127.0.0.1:4173/preview/ while the preview server is running.
Import GLB into Blender, Three.js GLTFLoader, or another glTF 2.0 viewer.

## Example runtime binding (future React application)

```tsx
import { useMemo } from 'react';
import { useGLTF } from '@react-three/drei';

function QKVInstrument({ assetBaseUrl }: { assetBaseUrl: string }) {
  const { scene } = useGLTF(`${assetBaseUrl}/qkv-projector.glb`);
  const instrument = useMemo(() => {
    const copy = scene.clone(true);
    copy.traverse(node => {
      if (node.name.startsWith('demo_')) node.visible = false;
    });
    return copy;
  }, [scene]);
  // Add instanced cells/labels at each panel's socket_display anchor.
  // Scope lookup to the Q / K / V group because socket names are local.
  // Clone shared materials before changing one instance's appearance.
  return <primitive object={instrument} dispose={null} />;
}
```

The GLTF cache owns the shared geometry/material resources. Dispose of those
only when the entire experience and all dependent instances have unmounted.
